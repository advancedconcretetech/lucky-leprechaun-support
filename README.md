# Lucky Leprechaun Gold Hunt — GitHub Pages

Official support and privacy pages for Lucky Leprechaun Gold Hunt, published by ADVANCED CONCRETE TECHNOLOGIES, LLC.

## Publish
1. Create a new **public** GitHub repository, for example `lucky-leprechaun-support`.
2. Upload `index.html`, `privacy.html`, and `styles.css` to the **root** of the repository (not inside a subfolder).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and click **Save**.
5. Wait for GitHub Pages deployment, then verify both links in a browser.

If your GitHub username is `YOUR-USERNAME` and the repository is `lucky-leprechaun-support`:
- App Store Connect **Support URL**: `https://YOUR-USERNAME.github.io/lucky-leprechaun-support/`
- App Store Connect **Privacy Policy URL**: `https://YOUR-USERNAME.github.io/lucky-leprechaun-support/privacy.html`
- **Marketing URL**: leave blank.

## Important before publishing
- Confirm that the app truly has **no real-money gambling or cash prizes**.
- Confirm the OneSignal configuration and the actual data collected against the OneSignal SDK version, app permissions, and App Store Connect **App Privacy** responses. The policy describes possible notification-related data, not a verified technical audit.
- Confirm the company address and support email are accurate and publicly usable.
- No advertising section is included because advertising is not currently implemented. Update the policy and App Privacy disclosures if data practices change.
